## SVG와 무엇이 다른가

| 항목         | SVG           | Canvas           |
| ------------ | ------------- | ---------------- |
| 요소         | DOM 노드      | 픽셀만           |
| hover·클릭   | 이벤트 그대로 | 좌표로 직접 판정 |
| 접근성       | 붙일 수 있음  | **없음**         |
| 선명도       | 자동          | DPR 직접 처리    |
| 요소 수천 개 | 느려짐        | 문제없음         |
